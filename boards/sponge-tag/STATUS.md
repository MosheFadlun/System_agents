## Tooling notes
- Schematic: `03-schematic/sponge_tag.kicad_sch` (+ `sponge_tag.pdf`), generated by `sponge_tag.py` in
  SKiDL label mode (nets joined by labels, no drawn wires). nRF54L15 symbol: `lib/nRF54L15.kicad_sym`,
  generated from the datasheet pin table by `lib/make_nrf54l15_symbol.py`.
- KiCad ERC: 0 errors except 1 waiver. **W-1:** U1 nRESET "input not driven". It is pulled up on-chip
  and driven open-drain by the debugger, so this is expected. 44 warnings are `lib_symbol_mismatch`
  (SKiDL embeds simplified symbol copies); no connectivity impact.
- Auto-routed wiring mode (`mode="normal"`) hung for more than 5 min on this design; label mode is used instead.
- Firmware: on hold at the user's request (2026-10-18). Code in 08-firmware/ is not compiled; NCS `west update` was stopped partway.
